# Q7：存在比 C 单独更好（acc > 0.927）且成本更低的级联解吗？——有，且单调约束恰好挡住它

> **状态**：已解决（可继续追问）
> **日期**：2026-09-14
> **关联**：[总览笔记](../LLM_cascade_optimizer_notes.md) §7 · [Q6](Q6_quantile_grid_alive_simplex.md) §4.3（单调约束实验） · 演示页 STEP 5/7（b 滑块已放宽至 0.036）
> **数据**：n=2000、固定 L=(A,B,C)、b 扫描 0.008–0.046、每档约束版与无约束版各跑 网格 40×40 + Nelder-Mead

---

## 问题原文

> 有某个参数下，能找到比 C 效果还要好（超过 0.927）成本比 C 要低的解吗？测试一下，b 可以放宽一些。

---

## 结论（TL;DR）

**有。** b ≈ 0.024–0.032 时，**无约束**级联达到 acc ≈ 0.9290–0.9295 **> C 单独的 0.9270**，
成本 0.0232–0.0275 **< C 单独的 0.0359**（约 C 的 65–77%）——精度、成本双轴全胜。
且 **`u₁ ≤ u₂` 约束版永远到不了**：亚 C 成本下最高 0.9250，只有退化成 C 本身（花满预算）才追平——
单调约束把"超过最强单模型"的解挡在了可行域外，是它又一条实际代价。

收益的机制：难度带内 C 逐带优于 A/B，但个别查询存在**抖动反转**（A 对 C 错），
级联路由能保住其中一部分；预言机上限（任一模型答对即算对）为 0.9700，说明空间远未触及——
**模型越多样，这一增益越大**，这正是论文"级联可提升精度"主张的机制。

| 0.008 | 0.8935 / 0.0080 | 0.8935 / 0.0080 | |
| 0.012 | 0.9095 / 0.0115 | 0.9150 / 0.0117 | |
| 0.016 | 0.9160 / 0.0160 | 0.9185 / 0.0146 | |
| 0.020 | 0.9190 / 0.0191 | 0.9235 / 0.0190 | |
| **0.024** | 0.9250 / 0.0239 | **0.9290 / 0.0232** | ★ 双轴全胜 |
| 0.028 | 0.9250 / 0.0247 | **0.9295 / 0.0275** | ★ |
| 0.032 | 0.9250 / 0.0237 | **0.9295 / 0.0275** | ★ |
| 0.036+ | 0.9270 / 0.0359（退化为 C） | 0.9295 / 0.0275 | ★ |

要点：
1. **无约束版在 b≈0.024 处双轴全胜 C**：+0.20pt 精度、成本仅 65%；
2. b 再放大，acc 升至 0.9295（+0.25pt）后饱和——它**不会**退化成"C 本身"：
   目标只有 −acc，成本只要不超预算即可，算法没有动机花光预算；
3. **约束版天花板 0.9250**（亚 C 成本段），永远追不上 0.927——递增约束
   在此再度成为纯粹的性能损失（与 [Q6](Q6_quantile_grid_alive_simplex.md) §4.3 结论一致）。

## 为什么能超过最强单模型（机制）

- C 单独：每条查询都由 C 作答，acc = E[r_C] ≈ 0.927。
- 级联在 A/B 处"截胡"了一部分查询。每截胡一条，期望得失 = p_A/B(i) − p_C(i)：
  难度带内通常为负（C 更强），但**逐查询存在抖动反转**（如 p_A=0.98、p_C=0.92 的个别查询），
  截胡即得利。门控按 A/B 自身打分路由，能捕获其中一部分。
- 增益上限由"模型并集"决定：任一模型答对即算对的比例 = **0.9700**（预言机上限）。
  级联 0.9295 已从 C(0.927) 向上限推进了约 1/8 的差距。
- **推论**：A/B/C 同质（各带 C 全面碾压）时增益趋近 0；模型多样性越高、
  "便宜模型在某类查询上反超贵模型"的比例越大，级联超越最强单模型的空间越大——
  这是论文 Tradeoff 图中"级联点高于最强单模型"曲线的成因。

## 边界情况与注意点

- acc > C 的增益依赖打分器质量：错位率升高时，截胡收益被"答错却高分"的误采纳抵消；
- b > C 成本后约束版退化为 C 本身（0.9270/0.0359），曲线饱和——Tradeoff 图右端点的来源；
- 扫描用 Ns=40 + NM；页面用 Ns=20 结论一致（演示时 acc 可能 ±0.1pt 浮动）。

## 总结

存在：b ≈ 0.024–0.032 时无约束级联 **0.9290–0.9295 @ 0.0232–0.0275**，精度与成本双轴优于
C 单独（0.9270 @ 0.0359）；`u₁ ≤ u₂` 约束版则完全无法超过 C。增益来自"便宜模型在个别查询上
反超最强模型"的抖动反转被门控捕获，上限由模型并集（预言机 0.970）与打分器质量共同决定。
