STEP 1 · construct_data：期望 → 三张矩阵

先把"期望"折叠成 200×3 的查表（此后零 LLM 调用）

把 3 个 API 对全部 200 条查询离线各调一次并缓存，构造三张矩阵：

\(q_i\)：第 \(i\) 条查询；\(a_i\)：它的真实答案；\(f_{L_j}(q)\)：链上第 \(j\) 级 API 对 \(q\) 的回答

\(r(\cdot)\in\{0,1\}\)：正确性判定（exact match）。\(\;R_{ij}=r\big(a_i, f_{L_j}(q_i)\big)\) ——第 \(i\) 条查询用第 \(j\) 级 API 答对了吗

\(c_{ik}\)：第 \(i\) 条查询调用第 \(k\) 级 API 的单次成本。\(\;C_{ij}=\sum_{k\le j} c_{ik}\) ——累计成本（到第 \(j\) 级停机时花的钱）

\(D_{ij}=1-g(q_i, f_{L_j}(q_i))\) ——失败概率（compute_dist）

目标里的期望换成 200 行上的求和（样本平均近似 SAA）， 之后整个求解过程就是在这三张表上做 numpy 式运算。

STEP 2 · f(delta)：给定 τ 模拟一遍级联

τ 定了，200 条查询各停在哪一级、目标值就是两个求和

拖动下面两个滑块（失败空间：调大 = 放宽）。接受规则与首站停：

\(\tilde A_{ij}=\mathbf{1}\{D_{ij}<\tau_j\}\)，\(\;z_i=\min\{j:\tilde A_{ij}=1\}\)，\(\;\tau_3\equiv 1\)

\(\widehat{\mathrm{acc}}=\tfrac1n\sum_i\sum_j A_{ij}R_{ij}\)，\(\;\widehat{\mathrm{cost}}=\tfrac1n\sum_i\sum_j A_{ij}C_{ij}\)

每行恰好一个 1（停在 \(z_i\)），内层求和自动取出 \(R_{i,z_i}\) 与 \(C_{i,z_i}\)。 预算按样本版约束判：\(\sum A\circ C \le b\cdot n\)，违反即罚 10000 （\(\circ\) = 逐元素相乘；\(A\) 是首站停修正后的接受指示矩阵）。

留意：调大 \(\tau_1\) 让 A 多接题 → acc 可能不升反降（A 接住错题），cost 单调下降——这就是阶梯地形的两股力量。

\(\tau_3 = 1\)（固定）

着色 = 该查询在此 τ 下实际停机的级别（每列一格）。悬停看该查询走向。

STEP 3 · 阶梯地形：目标为什么没有梯度

固定 \(\tau_2\) 扫 \(\tau_1\)：只在断点跳变，断点之间是平台

\(\boldsymbol\tau\) 只通过 \(n\) 个指示函数 \(\mathbf{1}\{D_{i1}<\tau_1\}\) 进入目标 ——单个指示符在 \(\tau_1=D_{i1}\) 处跳一次，有限和仍是阶梯。 断点集合 = 观测距离 \(\{D_{i1}\}\)（下图竖虚线，≤200 个）。

后果：平台内梯度处处为 0，且 0 梯度 ≠ 最优（右下平台比中间平台差）， 梯度类算法（GD/L-BFGS）全部失效——这决定了后面只能"网格 + 无梯度单纯形"。

STEP 4 · quantile 参数化与 alive 集合

不搜 τ，搜"升级比例 \(u\)"；分位数只在到达者（alive）上取

优化变量换成 \(u=(u_1,u_2)\in(0,1)^2\)——每级的升级比例（quantile 水平， 放行 \(1-u_j\)、存活 \(u_j\)）。门限由经验分布反解：

\(\mathrm{alive}_1=\{1..n\}\)，\(\;\tau_j=\operatorname{Quantile}\big(D[\mathrm{alive}_j,j],\ 1-u_j\big)\)，\(\;\mathrm{alive}_{j+1}=\mathrm{alive}_j\cap\{D_{ij}\ge\tau_j\}\)

\(\operatorname{Quantile}(x,\,q)\)：把 \(x\) 从小到大排序、取 \(q\) 分位数（numpy 线性插值实现，见 analysis/qa/Q6 §B2 的小例子）。

右图是经验 CDF：纵轴是 quantile 水平，横轴是分数 \(D\)。例如 \(u_1\) 每取一个值， "放行 \(1-u_1\)、升级 \(u_1\)"——在蓝线高度 \(1-u_1\) 处读出对应的 \(\tau_1\)（见虚线引导）。 蓝色曲线管第 1 级（全体），绿色曲线管第 2 级（只统计 alive，即第一级没接住的人）。

为什么必须在 alive 上取：线上到达第 2 级的，是第一级未采纳（升级）的那批—— 被采纳的查询已经拿到答案返回，不会走到第 2 级（条件分布）。 勾选下方对照可看"误用全体取分位"的错配。

u 轴被经验分位数均匀切成 ~n 段、每段恰对应一个单元格——u 网格的每个点必命中一个新单元格，τ 空间均匀网格做不到（详见 analysis/qa/Q6）。

STEP 5 · scipy.optimize.brute：40×40 网格粗搜

在 \(u\) 平面撒 1600 个点，每个点必命中一个不同单元格

网格 = \(\mathrm{linspace}(10^{-5},\,1{-}10^{-5},\,40)\) 的笛卡尔积。颜色 = 该点的 \(\widehat{\mathrm{acc}}\)（越深越高）：

\(G(u_1,u_2)=\begin{cases}10000,&u_2<u_1\ \text{（违反单调约束）}\\10000,&\widehat{\mathrm{cost}}>b\\-\widehat{\mathrm{acc}},&\text{否则}\end{cases}\)

记作 \(G\) 是因为它在 optimizer.py 里恰好也叫 g——与打分器 \(g\) 撞名，此处改名以免混淆。

灰色 = 单调区外（对角线下方）；红色 = 超预算。白星 = 网格最优， 它将作为下一步 Nelder-Mead 的起点。

为什么按 u 而不是按 τ 撒点：单元格宽度由数据密度决定（τ 轴上极不均匀）， 而 u 轴上单元格等宽 ~1/n——同样 1600 次评估，覆盖质量完全不同。

悬停任意格点：u、反解出的 τ、acc、cost。数据由本页实时计算（node 端可复现）。

对照实验结论：勾选关闭约束后，最优解会移入 \(u_2<u_1\) 区域——演示数据上四个预算的精度分别提升 +7.5 / +2.5 / +1.5 / +2.0 个百分点；留出集实验（30 次随机 140/60 划分）同样显示无约束版本测试精度 +0.4~2.3pt、胜率约 2/3——"正则化"辩护在该数据上不成立。该约束是代码层启发式（论文未提及），详见 analysis/qa/Q6 §4.3。

STEP 6 · finish=fmin：Nelder-Mead 单纯形局部细化

一个三角形在最优格点附近做"反射 / 扩张 / 收缩 / 缩边"

单纯形（simplex）= 2 维空间中 3 个顶点的三角形。Nelder-Mead 只比较函数值大小，每轮：

① 反射：最差顶点 \(W\) 沿其余两点重心 \(\bar c\) 翻到对面 \(W'=\bar c+(\bar c-W)\)
② 反射点更优 → 扩张 \(W''=\bar c+2(\bar c-W)\)
③ 一般 → 直接接受；更差 → 收缩（向重心缩一半）
④ 全都差 → 缩边：整三角形向最优点收拢
初始三点（scipy fmin 约定，起点 = 网格最优 \((u_1^{g},u_2^{g})\)）：
\(V_0=(u_1^{g},u_2^{g})\)，\(\;V_1=(1.05\,u_1^{g},\ u_2^{g})\)，\(\;V_2=(u_1^{g},\ 1.05\,u_2^{g})\) ——沿两个坐标轴各偏 5%

终止：顶点间最大坐标差 ≤ xatol=10⁻⁴ 且 f 差 ≤ fatol=10⁻⁴，或达 400 轮上限

为什么本例约 10 轮就停，而 f 只在前几轮变化：本例 f 在第 3 轮登上最优平台 （跨越了一条单元格边界），其后所有试探点的 f 完全相同——比较 f 已无法区分方向 （这就是"零信息"），算法唯一能做的是向最优点几何收缩：顶点逐轮减半靠近， 直到逐轴散布 ≤ 10⁻⁴ 触发终止。下表顶点显示 5 位小数，能看到第 8~11 轮仍在收敛。

"始终在一个平台上？"——对，且这是精确陈述：平台 = 一组相邻单元格的并（目标值相同）。 关键在于单元格内部的目标是精确恒定，不是"近似恒定"——所以"粗网格 → 细网格"的直觉 只在跨越单元格时有意义，单元格内部不存在可被细化发现的更细结构。 u 轴单元格宽约 1/n = 0.005 ≫ 容差 10⁻⁴，因此单纯形一旦缩进最优单元格（约第 8 轮）， 剩余迭代必然零变化。n 越大单元格越窄；若单元格宽小于容差，单纯形会横跨多格、 f 持续变化，形态就完全不同了。

它没有梯度、也没有全局机制（可能停在非最优平台），所以只从网格最优点出发做局部打磨—— 这就是 finish=fmin 的分工：网格管全局，单纯形管精修。

拖动滑块或点"播放"，看三角形逐步变形；白折线是历轮最优点的轨迹。 STEP 5 的对照开关同样作用于本步：关闭约束时，单纯形在无约束目标上运行（起点 = 无约束网格最优）。
