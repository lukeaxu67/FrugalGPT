## 关键语义（与论文的对应）

- **D = 1 − g**（失败概率），接受条件 `D < τ`——**代码的 τ 是失败上限，越大越宽松**；
  论文的 τ 作用在 g 上（`g ≥ τ` 接受，越大越严格）。换算：`τ_code = 1 − τ_paper`。
  详见 `analysis/qa/Q5_tau_semantics.md`。
- **u = `qual`**：第 j 级的**升级比例**（quantile 水平）——放行 `1−u_j`、存活 `u_j`；
  τ_j = Quantile(D[alive_j], 1−u_j)。分位数只在 alive（真实到达者）上取。
- **τ₃ ≡ 1**：末级必答（兜底），不参与搜索，自由变量只有 (τ₁, τ₂)（见 `Q1`）。
- **阶梯函数**：目标对 τ 分段常数、断点 = 观测距离（见 `Q4`）——这是"网格 + 无梯度
  单纯形"选型的根本原因（见 `Q3`）。

## 演示数据（可复现）

`generateDataset(200, seed=20260913)`：难度四带混合
（简单 68% / 中等 15% / 困难 12% / 极难 5%），
`p_ij` 为带内基线 ± 抖动，`correct ~ Bernoulli(p)`，`score = p + 0.08·N(0,1)`
（约 10% 错位 → 打分器不完美），成本按答案长度微扰。
单 API 基线：acc ≈ 0.66 / 0.82 / 0.94，成本 \$0.001 / 0.005 / 0.030。

预算 b=0.006 下完整求解结果：`u* ≈ (0.316, 0.335)`、`τ* ≈ (0.302, 0.675, 1)`、
acc ≈ 0.835、cost ≈ 0.0059（C 单独 0.940 @ 0.0357 的 ~16% 成本）。
选 b=0.006 的原因：此预算下 Nelder-Mead 会在第 3 轮把 acc 从 0.830 提升到 0.835
（能直观看到"局部细化"的价值；b=0.008 时网格最优已无法被 NM 改进）。

## 验证

```bash
node tests/core.test.js
```

26 项断言：矩阵构造（前缀和、D=1−g）、级联模拟不变量（τ→0 等价 C 单独、τ=1 等价
A 单独、首站停独立复核）、numpy linear 分位数对拍、alive 掩码语义、单调罚、
Nelder-Mead 在光滑函数上收敛、全预算扫描下 NM 不劣于网格最优。

## 已知取舍

- 网格 Ns=40 是"计算预算 × 采样噪声 × 覆盖保证"的工程平衡（见 `Q6` §2.3–2.4）；
  训练集最优 ≠ 真实最优（SAA 选择偏差，见 `Q2`）。
- `u₁ ≤ u₂` 单调约束出自原作者代码（`optimizer.py:86-88`），与实现的逐级条件语义错配；演示数据实验
  （含 30 次留出划分）显示去掉它可提升测试精度 0.4–7.5pt，**结论：不应加**
  （页面 STEP 5/6/7 有联动对照开关，实验记录见 `analysis/qa/Q6` §4.3）。
