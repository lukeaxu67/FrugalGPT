# Q2："无闭式期望"是什么意思？是期望就没有解析形式吗？

> **状态**：已解决（可继续追问）
> **日期**：2026-09-13
> **关联**：[总览笔记](../LLM_cascade_optimizer_notes.md) §1 难点2 · [Q1](Q1_tau3_fallback.md)

---

## 问题原文

> 无闭式期望：目标与约束都是期望，只能用样本估计，没有解析形式。——这句话不理解，如果不是期望就可以有解析形式吗？

---

## 结论（TL;DR）

**不是。** 决定目标函数能否"解析求值"的不是它**是不是期望**，而是**积分的分布和被积函数是否已知可写**：

- 是期望、但分布已知（如高斯/均匀）→ 常常**有**闭式，甚至是最好处理的一类；
- 不是期望、但是黑盒函数（如仿真输出）→ 照样**没有**解析形式；
- 本论文踩中的是第三种：是期望、且分布（用户查询 + LLM 行为 + 打分器行为）**写不出来** → 积分不可计算。

解决方法：用 n 条训练查询的**样本平均代替期望**（随机规划标准做法 SAA）。
这就是三个预计算矩阵存在的全部理由——它们把"未知分布上的积分"折叠成"有限训练集上的求和"。

---

## 详细分析

### 1. 优化算法真正需要的是什么？

任何优化算法（无论梯度法、单纯形还是网格搜索）都需要一个基本能力：

> **给定任意一组候选决策变量，能确定地算出目标函数与约束的值。**

- LP/QP 求解器还额外要求这个值能写成决策变量的显式公式（线性/二次），
  从而可以求梯度、写 KKT 条件、证明凸性。
- "有解析形式"通常就是指：目标 = 决策变量的可微（至少可精确求值）公式。

### 2. 三类目标对比

| 目标类型 | 例子 | 精确求值 | 微积分/标准求解器 |
|---|---|---|---|
| 显式代数函数 | `max 3x+2y s.t. x+y≤4` | ✅ 代入即算 | ✅ LP 直接解 |
| **已知分布**的期望 | 报童问题 D~U[0,100]；组合 r~N(μ,Σ) | ✅ 积分出闭式 | ✅ 求导置零 / 凸优化 |
| **未知分布**的期望 | **本论文** E_q[r(a, f_Lz(q))(q)] | ❌ 只能采样 | ❌ 先得近似 |
| 非期望黑盒 | CFD 仿真升力作目标 | ⚠️ 数值求值一次可行，无公式 | ❌ 黑盒优化 |

注意第二行：**"是期望"本身不排除闭式**。E[wᵀr] = wᵀμ 是线性代数式；
报童问题的期望成本可以积成决策量的显式函数再求导。
期望有闭式的条件是：**分布的密度/参数已知**。

### 3. 本论文的期望为什么积不出来

$$E_{q\sim Q}\big[r(a, f_{L_z(q)}(q))\big] = \int h(q)\, dQ(q)$$

被积对象 h(q) 串起了三重未知之物：

1. **Q：查询分布**——"未来用户会问什么问题"没有参数化的密度函数；
2. **f_L(q)：LLM 行为**——模型对每个问题的回答是否正确，是黑盒随机变量；
3. **g(·)：打分器行为**——决定级联在哪级停下，进而决定 h 的分段。

三者叠加，dQ 无从写出，∫h dQ 无法计算。约束里的 E[cost] 同理。
**论文公式里的 E[·]（main.tex:154-155）从未指定任何分布形式——它本质上是"对所有未来查询"的记号。**

### 4. 出路：样本平均近似（SAA）

$$E_{q\sim Q}[h(q)] \;\approx\; \hat{E}_n[h] = \frac{1}{n}\sum_{j=1}^n h(q_j)$$

把 n 条训练查询当作"整个世界"：期望退化为求和，随机问题折叠成**确定性**组合优化问题。
这就是统计学习/随机优化里的标准套路（Monte Carlo 估计 + SAA），
大数定律保证 n→∞ 时样本平均收敛到真期望。

**代价有两条，且都塑造了后续的算法设计：**

1. **采样误差**：̂E_n ≠ E。在训练集上选出的 (L, τ) 可能过拟合训练样本 → 需要留出集检验
   （代码的 `train_test_split`，论文的 train/test 划分，main.tex:179）。
2. **阶梯结构**：样本平均作为 τ 的函数是分段常数（每条查询的接受/拒绝只在 τ 跨过其观测值时翻转）
   → 梯度法失效 → 引出 quantile 参数化 + 网格 + Nelder-Mead（见 Q1 之后的内层求解设计，详见总览笔记 §3）。

## 代码证据

### 证据 1：三个矩阵就是"求和代替积分"的数据结构（`optimizer.py:28-56`）

`construct_data` 返回的 `L_mat / C_mat / d_mat`，**每一行对应一条训练查询**，
分别给出该样本的正确性、累计成本、打分距离。期望中的 h(q_j) 被逐样本制表。

### 证据 2：经验期望的分子就是一次矩阵内积（`optimizer.py:80-84`）

```python
acc = numpy.sum(numpy.multiply(e_full, L_mat))     # = n × Ê[r]（样本平均 × n）
cost = numpy.sum(numpy.multiply(e_full, C_mat))    # = n × Ê[cost]
if cost > budget * len(L_mat):                     # Ê[cost] ≤ budget 的样本版约束
    return 10000
return -acc
```

除以 n 在返回处补上：`return -resbrute[1]/len(L_mat)`（`optimizer.py:135`）。
所以优化器搜索时优化的**全部内容**就是样本平均——"无闭式期望"这一困难在这里已经被 SAA 化解，
剩下的难点只剩阶梯结构（引出 quantile 技巧）。

### 证据 3：数据本身按"分布的样本"来组织（`llmcascade.py:105-108`）

```python
train, test = train_test_split(trainingdata, test_size=0.01)
model_perf_train = self.evaluateall(train, ...)
model_perf_test  = self.evaluateall(test, ...)
```

训练集 → 优化阈值；留出集 → 检验"经验期望最优"是否泛化。这正是对代价①（采样误差）的工程对策。

## 公式与数学推理

**命题（等价类视角）**：设查询空间上的真分布为 Q。优化问题

$$\max_{L,\tau}\; E_Q[h(\cdot; L,\tau)] \quad s.t.\; E_Q[c(\cdot;L,\tau)] \le b$$

中若 Q 未知，则 E_Q 不可计算；改用独立同分布样本 {q₁..qₙ} 后：

1. **无偏性**：E[̂E_n[h]] = E_Q[h]（样本平均是真期望的无偏估计）；
2. **相合性**：n→∞ 时 ̂E_n → E_Q a.s.（大数定律），SAA 解收敛到真解（随机规划标准结论）；
3. **但有限 n 下**：argmax 的̂E_n 的最优点 ≠ argmax 的 E_Q 的最优点
   ——阈值 τ 在训练集上被"挤"到恰好卡在某些样本的距离值上，存在 selection bias；
4. **阶梯性**：对固定样本集，̂E_n 作为 τ 的函数是分段常数
   （每段对应一种"哪些查询在哪级被接受"的划分；划分只在 τ 跨过样本观测值 d_i(q_j) 时改变）。
   这一步正是 Q1 中"末级 τ_m ≡ 1 是等价类规范代表"论证的同一原理在全门限上的推广。

## 边界情况与注意点

- **"解析形式"的两种含义**要分开：①能精确求值（黑盒仿真也行，慢但确定）；②能写成决策变量的
  可微公式（求梯度/凸性所需）。SAA 之后本问题获得了①但仍然没有②——这正是为什么内层用
  无梯度的网格 + Nelder-Mead，而不是梯度下降。
- 若分布**已知**（例如假设距离 d 服从某参数族），确实可以走"积出闭式 → 微积分"的路线；
  但该假设对 DistilBERT 打分器的输出分布并不成立，所以代码选择不假设、直接用经验分布
  （quantile 反解门限也是"只用经验分布、不假设参数形式"的同一哲学）。
- 样本量 n 与阈值自由度（m−1=2）相比很大，过拟合主要表现为"阈值卡在个别样本上"而非维度灾难。

---

## 总结

"无闭式期望"指的不是"期望天然没有解析形式"，而是**本问题的期望是对未知分布（查询 + 模型行为 + 打分器）
的积分，写不出被积密度，因此目标值无法精确计算**。是期望但分布已知时完全可能有闭式（高斯组合、报童问题）；
不是期望但函数是黑盒时同样没有解析形式。FrugalGPT 的对策是 SAA：用训练集上的样本平均代替期望，
三个预计算矩阵就是为此准备的数据结构，`f(delta)` 的一次求和就是一次目标求值。
SAA 化解了"算不出"，留下"阶梯结构 + 采样误差"两个残留难点，分别由 quantile 网格搜索和留出集检验应对。
